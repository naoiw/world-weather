# 機能仕様

## 目的

世界の主要都市の天気、気温、湿度、現地時刻を、回転する3D地球儀上で直感的に確認する。

## Phase 1：地球儀（実装済み）

- 地球儀をページ中央に配置し、地表画像を表示。
- マウスドラッグ／タッチスワイプによる経度方向の回転。
- 緯度方向の回転を制限し、常に地軸が垂直になる視点とする。
- ホイール／ピンチとUIボタンでズーム。視点リセットと自動回転切替。
- 画面のリサイズに追従。WebGL開始失敗時にはエラーメッセージを表示。
- 背景の星、大気の光、擬似的な照明を追加。

**注意:** 現段階の照明は演出であり、現在の太陽位置や実際の昼夜を表すものではありません。UTC表示もブラウザ時刻に基づきます。

## Phase 2：都市と天気（未実装）

- 主要都市（初期候補：東京、ソウル、北京、シンガポール、ニューデリー、ドバイ、ロンドン、パリ、ニューヨーク、ロサンゼルス、サンパウロ、シドニー等）。
- 都市の緯度経度をデータとして管理する。
- 天気API（候補：Open-Meteo）から気温、湿度、天気コード、取得日時を取得する。
- 地球の表側に見える都市のみ、引き出し線・ラベルを表示する。
- 複数ラベルの重なりを回避する。スマホでは表示数を間引く。
- API失敗時は取得失敗を明示し、架空の数値は表示しない。
- キャッシュと適切な再取得間隔を導入する。

## Phase 3：時刻と昼夜（未実装）

- 各都市のIANAタイムゾーンから現地時刻を計算。
- UTC時刻・日時・季節に基づく太陽方向の計算。
- 地球表面の日照／夜間の境界（ターミネーター）を反映。
- 都市光や夜間の表示調整を検討する。

## 非機能要件

- GitHub Pagesで動く静的Webアプリ。独自バックエンドを必要としない。
- PCとスマートフォンのタッチ操作に対応。
- APIキーや個人情報をリポジトリへ含めない。
- GPU負荷を抑えるためデバイスピクセル比を最大2に制限。
- WebGLが使えない環境や画像取得失敗時に致命的な白画面としない。
