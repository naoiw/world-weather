# 機能仕様

## 目的

回転する3D地球儀から、世界主要都市の気温・湿度・天気・現地日時を見渡せる、静的なGitHub Pagesアプリ。

## Phase 1：地球儀（実装済み）

- ドラッグ／タッチスワイプによる左右回転とホイール／ピンチでのズーム。
- リセット、自動回転、WebGLが使えない場合のエラー表示。
- 地表画像・大気の光・星空・レスポンシブUI。

## Phase 2：都市と天気（実装済み）

- 16都市の座標とIANAタイムゾーンを `src/lib/cities.ts` で一元管理。
- Open-MeteoのForecast APIへ緯度経度を配列で渡し、`current=temperature_2m,relative_humidity_2m,weather_code,is_day`を取得する。
- リクエスト時の`timezone=GMT`で観測時刻をUTCとして解釈。
- 20分間有効なセッションキャッシュ、30分ごとの再取得、タブ復帰時の更新と手動更新。
- 天気の取得失敗時はエラーを表示。取得済みデータは保持し、架空の気象値で埋めない。
- 地球儀の回転とズームに合わせて都市座標を投影。地球の裏側や地平線の向こうにある都市ラベルを隠す。
- 最大6都市を引き出し線で表示。狭い画面では3〜4件に制限し、左右にラベルを振り分ける。
- 都市ラベルまたはプルダウンの選択で詳細パネルを更新。

## Phase 3：現地時刻と昼夜（実装済み）

- `Intl.DateTimeFormat`とIANAタイムゾーンを使い、夏時間を考慮した現地日時を表示。
- UTC日時・季節から太陽赤緯、均時差、太陽直下点の概算を求める。
- 地球の各面の法線と太陽方向の内積で昼夜の明暗を切り替えるShaderを採用。
- 夜側は夜景テクスチャを表示。時間は1分ごとに更新する。
- 天気APIの昼夜判定は各都市の詳細欄に表示し、全球の昼夜は天文計算と独立させる。

## データ更新と限界

- データ取得は全訪問者のブラウザで発生する。セッションキャッシュと間隔で削減しているが、利用者増加時はGitHub Actionsでの定期取得＋静的JSON配布への切替を検討する。
- 使用条件はOpen-Meteoの非商用利用規約に従う。商用運用時には別契約が必要な場合がある。
- 現在値は数値予報モデルからの推定であり、都市の公式な観測値を保証しない。
- 太陽位置の計算は視覚的な概算であり、天文観測・航法目的に使わない。
- ラベルは視点の近い都市を優先し、全16都市を同時表示するわけではない。

## 非機能要件

- GitHub Pagesの静的配信。サーバー・APIキー不要。
- スマートフォンのスワイプ・ピンチに対応、GPU負荷を抑えるためピクセル比は最大2。
- API不調、画像取得失敗、WebGL非対応で壊れないようフォールバックを設ける。
- READMEと仕様は画面・API仕様を変更した際に更新する。
