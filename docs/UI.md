# UI方針

本アプリの画面デザインは他のProject Pagesとは独立させ、地球儀を主役にします。

- 深い紺色から黒を基調とし、青緑をアクセントに使う。
- PCでは地球儀を主役にし、右側パネルの先頭にAUTO ROTATEボタン、その下に選択都市の天気詳細と更新操作を配置する。
- 16都市の緯度経度から画面位置へ投影し、円形マーカーのみを描く。引き出し線や四角い天気カードは表示しない。
- すべての都市のマーカーを毎回評価し、画面サイズによる数の制限は設けない。
- 地球の背面・地平線の向こうは非表示。地球儀を回すと裏側の都市マーカーが現れる。
- 都市を選ぶと経度方向に約2.1秒の最短回転で移動し、手動回転で中断できる。上下回転は引き続き禁止。
- 通常のマーカーは青緑色、選択中のマーカーはオレンジ色で区別する。選択都市の変更時にはプルダウンと連動する。
- マーカーはクリック・タップ可能で、都市を選択すると右パネルの天気詳細が更新され、自動フォーカスが実行される。
- スマホでもマーカー数は減らさず、情報パネルを球体の下へ移動する。
- 天気APIの未取得・エラーを明示し、架空の数値を実際の観測値として示さない。
- `touch-action: none` で地球儀のスワイプ・ピンチ操作を優先。
- ブラウザのキーボードでマーカー・都市選択・AUTO ROTATEボタン・更新ボタンへアクセスできるようにする。
- NAVIGATIONガイド、拡大・縮小・リセットのボタン、地球儀下のキャプション、説明文は表示しない。ドラッグ・スワイプ・ホイール・ピンチ機能は残す。
- 昼夜は描画の演出ではなく太陽位置に連動。都市の現地時刻はIANAタイムゾーンで算出する。
