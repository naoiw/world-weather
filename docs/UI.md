# UI方針

本アプリの画面デザインは他のProject Pagesとは独立させ、地球儀を主役にします。

- 深い紺色から黒を基調とし、青緑をアクセントに使う。
- PCでは地球儀を中央に置き、左に状態表示、右に選択都市の詳細と回転操作を配置する。
- 都市の緯度経度から画面位置へ投影し、都市マーカーを線でラベルと接続する。
- 地球の背面・地平線の向こうは非表示とし、画面サイズに応じて最大3〜6都市に制限する。
- ラベルは左右の列に配置し、上下方向の重なりを回避する。マーカー表示位置は回転・ズームに追従する。
- 各ラベルはクリック可能で、詳しい都市情報が右側へ表示される。
- スマホでは情報パネルを球体の下へ移動し、ラベルをコンパクトにする。
- 天気APIの未取得・エラーを明示し、架空の数値を実際の観測値として示さない。
- `touch-action: none` で地球儀のスワイプ・ピンチ操作を優先。
- ブラウザのキーボードで都市選択・操作ボタンへアクセスできるようにする。
- 昼夜は描画の演出ではなく太陽位置に連動。都市の現地時刻はIANAタイムゾーンで算出する。
