# UI方針

このリポジトリは他のProject Pagesと同じ機能・文書運用を維持しつつ、**画面デザインは独立**させます。

- 地球儀を主役にする。情報量を増やす際も球体の視認性を損なわない。
- 背景は深い紺色〜黒。文字は白系、アクセントに青緑。
- 操作ガイドと操作ボタンはPCでは左右の空間に配置。スマートフォンでは球体の下へ移動。
- 回転は横方向のみ。不要な奥行き方向のパンを禁止。
- 主要操作はタップ可能なボタンで補助し、キーボードのTabでも操作可能にする。
- 天気の数値は取得に成功した場合のみ表示する。デモ値を実測値に見せない。
- 地球儀へのドラッグ／スワイプがスクロール等で奪われないよう `touch-action: none` を設定する。
- 今後都市ラベルが増えた際は裏面判定、重複回避、スマホ向け間引きを必須とする。
