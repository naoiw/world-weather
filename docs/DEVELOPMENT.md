# 開発・検証手順

## 必要環境

- Node.js 22以降、npm
- WebGL対応ブラウザ（Chrome / Edge / Firefox / Safariなど）

## ローカル起動・テスト

```bash
git clone https://github.com/naoiw/world-weather.git
cd world-weather
git switch develop
npm install
npm run dev
npm test
npm run build
npm run build:pages:develop
npm run build:pages:main
```

`npm test` はNode.js 22の型削除機能（`--experimental-strip-types`）と組み込みテストランナーでテストを実行します。`dist/` はGit管理しません。

## コード構成・責務

- `src/lib/cities.ts`：緯度経度・タイムゾーンを持つ都市マスターデータ。
- `src/lib/weather.ts`：Open-Meteoの要求パラメーターと応答検証、天気コード・風向変換、同一UTC時間帯の降水確率抽出。
- `src/hooks/useWeather.ts`：セッションキャッシュ、30分再取得、失敗時の旧データ保持。
- `src/lib/astronomy.ts`：球面座標とUTCベースの太陽直下点。
- `src/lib/globeLayout.ts`：最短経度回転・ラベルの表示優先度、衝突回避、横列安定化。Three.jsに依存しない純粋関数。
- `src/components/EarthGlobe.tsx`：WebGL描画・昼夜Shader・視野判定・都市ラベル。
- `src/App.tsx`：都市選択と操作パネル・取得状態の表示。

新しい都市は`cities.ts`に追加してください。天気取得・表示・日時計算は自動的にその都市へ適用されます。ラベルの最大表示数はパフォーマンスと重なりのため限定しています。

## 地球テクスチャと座標の整合性

Three.js の `SphereGeometry` を回転せず使用し、地球の正距円筒画像の経度0°を UV の `u=0.5` に合わせます。緯度0°・経度0°は +X、東経90°は **-Z**、西経90°は **+Z** です。都市座標と太陽方向は共通の `geoToCartesian()` を使います。

座標変換を変更した場合は `npm test` の都市とUVの照合テストに加え、プレビューで東京、パリ、サンパウロ、シドニーを表示してマーカー位置が地図と一致すること、昼夜の境界が地球の回転と矛盾しないことを確認してください。以前は Z の符号が逆で、サンパウロがマダガスカル付近に表示されていました。

## 手動確認

1. PCで地球が見え、左右にドラッグして都市ラベルと引き出し線が追従する。
2. プルダウンとラベルから遠方の都市（東京→ニューヨーク→シドニー）を選び、最短方向で経度が正面に移動する。
3. 自動移動中のドラッグ・スワイプ・ズームでアニメーションが止まり、操作できる。
4. AUTO ROTATEボタンが右パネル最上部にあり、オン・オフできる。都市を選ぶと自動回転が止まる。拡大・縮小はホイール・ピンチ操作でできる。リセットボタンは表示しない。
5. 欧州・東アジア等の密集地域でラベル同士が重ならず、中央を横切っただけで左右の列が頻繁に入れ替わらない。
6. 360px前後のスマートフォンではラベルが最大2件、選択した都市が見えている間は優先表示される。
7. 320pxのスマートフォンでもラベルや引き出し線が画面外へはみ出さず、都市の選択と操作ボタンが押せる。
8. OSの「視差効果を減らす」設定ではフォーカスが瞬時に切り替わる。
9. 地球の裏側に回った都市ラベルが非表示になり、別の地域が見えると入れ替わる。
10. 気温・湿度・天気コードがAPIの実データに基づき、失敗時に未取得と表示される。
11. 選択都市欄で体感温度・風速・風向・降水量・雲量・1時間降水確率が取得できる。地球儀のラベルに項目が追加されていない。
12. 降水確率が現在値と同じUTC時間帯の予報値であり、隣接時間・欠損値を勝手に表示しない。
13. 雨が0mm、降水確率が0%のときにダッシュでなく0を表示する。
14. 連続リロードで毎回APIを呼ばず、20分以内は保存データを利用する。
15. 現地日時が日本と欧米等で異なり、DSTも正しく処理される。
16. UTC時刻と一致した昼夜の境界が回転中も地表上の正しい場所に見える。
17. スマートフォンでスワイプ・ピンチ、AUTO ROTATEボタンと更新ボタン、ラベルのタップが使える。NAVIGATION・VIEW CONTROLS・地球儀下キャプション・旧説明文が表示されない。
18. スマートフォンで詳細欄が横にはみ出さず、数値と単位が読み取れる。
19. WebGLが使えない場合は説明が表示される。画像URLへの通信に失敗した場合も単色球が残る。
20. `/world-weather/develop/`のJS/CSSが404にならない。

CIは自動テストと型チェック・ビルドを行います。実機でのWebGL描画とタッチ操作は別途目視確認が必要です。

## 運用

作業ブランチ→`develop`へのPR→プレビュー動作確認→`main`へのPR。マージ後も`develop`は保持します。

## 外部データ・画像

- 天気：`https://api.open-meteo.com/v1/forecast`、ブラウザからアクセス。利用条件とレート制限に注意。
- 地球画像：`https://unpkg.com/three-globe@2.45.2/example/img/`。画像取得失敗時は色だけの球が残ります。
- ランタイムに秘密鍵や個人データは必要ありません。
