# WORLD WEATHER

世界の主要都市の天気を、インタラクティブな3D地球儀で確認するGitHub Pagesアプリ（開発中）。

- 本番（`main`、現在は準備中）：https://naoiw.github.io/world-weather/
- 開発プレビュー（`develop`）：https://naoiw.github.io/world-weather/develop/
- 機能・開発手順・仕様は[developブランチのREADME](https://github.com/naoiw/world-weather/blob/develop/README.md)と[docs](https://github.com/naoiw/world-weather/tree/develop/docs)を参照してください。

通常の機能実装は`develop`で行い、確認後に`main`へPRで反映します。
